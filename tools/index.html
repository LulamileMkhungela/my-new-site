Agent skill

PRD Creator

Turns a fuzzy idea into a locked PRD plus build-ready milestone prompts and a milestone log.

Workflow & files

.agents/skills/prd-creator/ + _build_plan/prd.md and one prompt per milestone

  1. Brain dump intake
  2. Format choice
  3. Core purpose
  4. Top-level features (in scope)
  5. Top-level out-of-scope
  6. Tech stack & starter template
  7. External integrations & credentials
  8. Data model
  9. Per-feature scoping
  10. Milestone breakout
  11. Write files

Interviews you about a repeatable process, then designs, writes and verifies a portable skill.

  4. Build it

  6. Verify & hand off

Agent skill

Favicon Creator

Generates the full favicon set from one icon and wires the meta tags into the codebase.

Workflow & files

.agents/skills/favicon-creator/ + favicon.svg (the set is built by the skill)

  1. Gather inputs from the user
  2. Locate the layout file
  3. Determine the public asset directory
  4. Generate the SVG for browser tabs
  5. Generate the raster source SVG
  6. Rasterize all sizes
  7. Wire up the meta tags
  8. Report what changed

Template

Starter

The Rails + React starter: conventions, agent instructions and deployment notes, already canonical.

Workflow & files

template/starter/

  1. Clone the template and bundle install
  2. Set the app name and credentials
  3. Create the database and run the seed
  4. Start the dev processes and open the app
  5. Read AGENTS.md before the first agent session
  6. Deploy with the Hatchbox guide

Convention

Agents canon

One canonical home for skills and instructions: .agents/skills + AGENTS.md, with symlinks for the holdouts.

Workflow & files

.agents/ + AGENTS.md + scripts/link-agents.sh

  1. Install every skill into .agents/skills/
  2. Write agent instructions to AGENTS.md
  3. Point CLAUDE.md at AGENTS.md
  4. Symlink .claude/skills to ../.agents/skills
  5. Never store a real skill inside a tool-specific path
  6. Bake the setup into the template repo
